# Brief Audience

Use this skill to identify the target player fantasy, session habit, pain/desire language, and return motive for a Roblox experience.

## Output

Return a filled **Player Motivation Profile** using `templates/psychology/player-motivation-profile.md`.

## Rules

- Assume Roblox players can leave quickly; optimize for fast-to-fun.
- Name the primary fantasy before talking about features.
- Call out likely session length and why the player comes back.
- End with 3 audience risks or mismatches.
