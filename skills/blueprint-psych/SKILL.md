# Blueprint Psych

Use this skill to generate a **Player Psychology Blueprint** from player desire backward.

## Output

Return:
- target fantasy,
- dominant drivers,
- loop intent,
- social role,
- progression role,
- monetization fit,
- fairness risks.

Use `docs/reference/player-psychology-framework.md` as the framework source.
