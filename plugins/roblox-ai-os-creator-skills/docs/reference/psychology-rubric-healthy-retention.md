# Rubric: Healthy vs Manipulative Retention

Pass when:
- return motive is clear without forced daily punishment
- comeback hooks help absent players recover
- timers are legible and fair
- monetization does not gate basic dignity or understanding

Fail when:
- streak loss is the main motivator
- completion windows are unrealistic
- players are punished for short sessions
- monetization turns frustration into the intended funnel
