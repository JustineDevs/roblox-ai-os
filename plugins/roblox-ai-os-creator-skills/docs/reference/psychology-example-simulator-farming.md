# Example: Simulator / Farming

- Use `$brief:audience` to target relaxed collectors who want visible farm growth in 5-15 minute sessions.
- Use `$blueprint:loop` to define plant -> harvest -> upgrade -> expand -> rebirth -> return.
- Use `$forge:progression` to build seeds, tool tiers, multipliers, and prestige resets.
- Use `$forge:daily-loop` for rotating crops, weather boosts, and comeback fertiliser packs.
- Use `$forge:community` for neighbour bonuses, shared markets, and co-op harvest events.
