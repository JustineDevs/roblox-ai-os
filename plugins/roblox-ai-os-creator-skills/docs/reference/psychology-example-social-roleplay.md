# Example: Social Roleplay / Community

- Use `$brief:motivation` to rank community + status above mastery.
- Use `$blueprint:social` to define parties, friend-presence loops, houses, clubs, jobs, and gifting.
- Use `$forge:status` for titles, cosmetics, room showcases, and visible club ranks.
- Use `$forge:event-loop` for themed weekends, town festivals, and comeback-exclusive decor.
- Use `$forge:fomo` to keep urgency fair with previews, reruns, and non-punitive catch-up.
