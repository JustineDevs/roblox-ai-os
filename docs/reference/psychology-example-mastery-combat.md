# Example: Mastery-Driven Combat / Strategy

- Use `$brief:motivation` to rank mastery first, then status and community.
- Use `$blueprint:psych` to map player desire to outplay, build optimization, and ranked recognition.
- Use `$forge:mastery` for move tech, counters, build branches, and challenge ladders.
- Use `$forge:status` for visible ranked emblems, seasonal titles, and replay highlights.
- Use `$forge:community` for duos, guild scrims, shared training, and spectating presence.
