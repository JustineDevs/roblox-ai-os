## 规范的创作者工作流

`$brief` -> `$blueprint` -> `$forge` / `$crew` -> `$autoforge`

对于 Roblox 实现工作，任何代码生成之前都必须先通过 pre-action gate：
- 收集参考资料
- 建立理解
- 统一术语
- 设计模块化文件树架构
- 然后才开始实现
