## 正規創作者工作流程

`$brief` -> `$blueprint` -> `$forge` / `$crew` -> `$autoforge`

對於 Roblox 實作工作，在任何程式碼產生之前都必須先通過 pre-action gate：
- 蒐集參考資料
- 建立理解
- 統一術語
- 設計模組化檔案樹架構
- 然後才開始實作
