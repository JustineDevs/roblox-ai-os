## 정식 크리에이터 워크플로우

`$brief` -> `$blueprint` -> `$forge` / `$crew` -> `$autoforge`

Roblox 구현 작업에서는 어떤 코드 생성보다 먼저 필수 pre-action gate가 적용됩니다:
- 참고 자료 수집
- 이해 형성
- 용어 표준화
- 모듈형 파일 트리 아키텍처 설계
- 그 다음에만 구현
