## 正規のクリエイターワークフロー

`$brief` -> `$blueprint` -> `$forge` / `$crew` -> `$autoforge`

Roblox 実装作業では、コード生成の前に必須の pre-action gate を通す必要があります。
- 参照資料を集める
- 理解を構築する
- 用語を標準化する
- モジュール化されたファイルツリー設計を行う
- その後に実装する
